校板 BanGo 0.1.0 測試版

把五所高中的校網公告整理成好讀的時間軸，不用登入就能看。

校板 BanGo 0.1.0 測試版推出。校板把學校網站的公告整理成好讀的時間軸，目前支援師大附中、建國中學、北一女中、成功高中和中山女高。

主要功能

  • 我的公告：訂閱想看的類別和主題，只看跟自己有關的公告。
  • 分類瀏覽：依類別、主題或來源查看，也能搜尋。
  • 公告內頁：顯示內文、圖片、附件和參考網站，PDF 可以直接閱讀。
  • 外觀：調整語言、字體和顏色主題，支援深色模式。

隱私

校板只讀取校網的公開公告，不需要登入就能使用。

更新頻率

公告大約每 10 分鐘檢查一次。目前沒有推播通知，打開 App 或下拉就能更新。分類靠標題判斷，考試、繳費和報名期限請以校網原文為準。

安裝

iPhone

需要 iOS 26 以上，以自己的 Apple ID 簽名安裝。免費 Apple ID 簽的 App 每 7 天要重簽一次。

Android

打開 APK，依畫面提示允許安裝未知來源的 App。下載頁提供的安裝檔支援 64 位元（arm64）手機。這一版的套件 ID 和更早的 0.1.0 不同，裝好後請移除舊的 App。
