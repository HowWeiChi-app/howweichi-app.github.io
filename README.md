# HowWeiChi 開發者官網

HowWeiChi 開發者官網介紹捲字 JuanGo 和校板 BanGo，並提供下載連結。網站放在 GitHub Pages：<https://howweichi-app.github.io/>

## 專案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 首頁 |
| `juango/` | 捲字 JuanGo 介紹頁 |
| `bango/` | 校板 BanGo 介紹頁 |
| `xiaoban/` | 舊網址，自動導向 `bango/` |
| `pro/` | Pro 方案介紹（不賣訂閱，付款都在 App 裡） |
| `privacy/`、`terms/`、`support/` | 隱私權政策、服務條款、支援和刪除帳號說明（商店審核用） |
| `free-year/`、`redeem/`、`promo-terms/` | 「發一篇文，免費用一年」活動頁、兌換頁和活動辦法 |
| `js/updates.json` | 首頁「最新進度」的資料，改這個檔就會更新 |
| `img/og/` | 社群分享預覽圖（1200×630，由上一層的 `og_images.swift` 產生） |
| `css/` | 網站樣式 |
| `js/` | 卡片列、輪播和裝置篩選 |
| `img/` | 圖示和 App 畫面 |
